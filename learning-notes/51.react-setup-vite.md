# Day 51 — React Setup with Vite

## What is Vite?
A build tool that converts JSX into browser-runnable JavaScript and runs 
a fast local dev server with instant updates (Hot Module Replacement).

## Project structure created
decision-journal/
  backend/    - existing Express/MongoDB API
  frontend/   - new React app (separate project, own node_modules)

## Key files
- index.html: the ONE real HTML page — has just <div id="root"></div>
- main.jsx: bridges React to that div via ReactDOM.createRoot().render(<App />)
- App.jsx: the main component, starting point for all UI (rewritten from Day 52)

## Why frontend and backend are separate folders
They're independent applications that will communicate over HTTP (fetch 
calls, starting Day 58) — not sharing code directly, mirroring real-world 
MERN project structure.

## Single Page Application (SPA)
React apps typically have only one real HTML file; React dynamically 
injects/updates content into a single root div as the "page" changes.

## How it fits into Decision Journal
This frontend/ folder replaces the vanilla JS frontend (Phase 2-3) going 
forward, eventually calling the Express API (backend/) we've spent 
Phases 4-7 building.

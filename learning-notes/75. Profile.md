# Day 75 — Profile

## /me endpoints
Identity comes from the JWT (req.user.userId), not the URL, so a user can
only ever access their own data.

## Excluding fields
.select("-password") removes the password hash from query results.
Never return password hashes in API responses.

## Mass assignment
Never pass req.body directly into an update for sensitive models. Whitelist
allowed fields instead (here: only `name`).

## pre("save") hooks vs findByIdAndUpdate
The Day 45 hashing hook runs on .save()/.create(), NOT on findByIdAndUpdate.
A password written via findByIdAndUpdate would be stored as plain text.
Password changes need findById -> set -> .save().

## JWT payload fields
Token contains { userId, email } (set on Day 48), so the controller reads
req.user.userId.

## How it fits into Decision Journal
Users can view and edit their own profile. First feature that depends on
WHO is making the request, a stepping stone toward per-user data ownership.

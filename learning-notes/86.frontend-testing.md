# Day 86 — Frontend Testing

## Tools
Vitest (runner), jsdom (fake browser in Node), React Testing Library (test like
a user: roles, labels, text), user-event (realistic clicks/typing), a fake
fetch (mockApi) instead of the real backend.

## Queries
getBy = must exist now; findBy = waits (async); queryBy = may not exist.

## What I tested
Validators (pure), useFetch (loading, error, stale response ignored, reload),
GoalCard/Dashboard/GoalForm components, and whole-app flows: routing, login,
token storage and use, expired token redirect, logout, backend down + retry,
create/toggle/delete a goal, search.

## Regression test
"Stays on /decisions" fails if the Decisions page is replaced by the Signup
page — the exact bug I hit.

## Gotchas
Fake backends can have bugs too (status field confusion). Always await
user-event calls. Tests must be able to fail — prove it by breaking the code.

## How it fits into Decision Journal
Frontend behavior (auth redirects, forms, error states) is now protected by 50
automated tests, alongside the backend tests from Day 85.

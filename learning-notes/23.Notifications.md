# Day 23 - Notifications

## What is User Feedback?

User feedback is information provided by the application after a user performs an action. It helps users understand whether an operation was successful or if something went wrong.

---

## Why are Notifications Important?

Notifications improve user experience by giving immediate feedback. They reduce confusion and make the application easier to use.

---

## Difference Between Notification Types

### Success

Indicates that an operation completed successfully.

Example:
- Goal created successfully.
- Goal updated successfully.

### Error

Indicates that something went wrong.

Example:
- Goal title cannot be empty.
- Invalid deadline.

### Warning

Alerts the user about something important, but the operation can still continue.

Example:
- Deadline is today.

### Information

Provides useful information without indicating success or failure.

Example:
- No matching goals found.

---

## Why are Toast Notifications Better than Alerts?

Toast notifications do not interrupt the user. They appear briefly, provide feedback, and disappear automatically. Unlike alerts, users do not have to click an "OK" button to continue using the application.

---

## Why Should Notification Logic Be Reusable?

A single notification function can be used throughout the application for different actions like create, update, delete, validation, and search. This reduces code duplication and makes the application easier to maintain.

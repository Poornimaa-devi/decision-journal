# Day 43 — Authentication Concepts

## Authentication vs Authorization
- Authentication = proving WHO you are (login)
- Authorization = deciding WHAT you're allowed to do once identified

## Why authentication is needed at all
HTTP is stateless — every request is treated independently, with no memory 
of previous requests. Without authentication, there's no way to know "who" 
is making each API call.

## Two strategies
- Session-based: server stores session data, sends a session ID cookie
- Token-based (JWT): server signs a token containing identity info; client 
  sends it back each time; server verifies signature, no storage lookup needed

## Why JWT for Decision Journal
- Industry standard for REST APIs
- No server-side session storage needed
- Works well with a separate React frontend (Phase 8-9)

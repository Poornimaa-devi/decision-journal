# Day 83 — Responsive Design

## Mobile-first
Write the small-screen layout as the default, then add min-width media
queries for larger screens. Breakpoints in rem (40rem ≈ 640px).

## Viewport meta tag
<meta name="viewport" content="width=device-width, initial-scale=1.0">
Without it phones render at ~980px wide and shrink the page.

## Flexbox vs Grid
Flexbox = one direction (nav links that wrap). Grid = two dimensions
(cards in rows and columns).

## Responsive without media queries
grid-template-columns: repeat(auto-fill, minmax(min(100%, 16rem), 1fr));

## Units
rem for spacing/type/breakpoints (respects user font size), px for borders,
% and fr inside layouts, clamp(min, preferred, max) for fluid type.

## Usability details
44px minimum touch targets; inputs ≥16px (iOS zoom); keep a visible
:focus-visible outline; box-sizing: border-box; overflow-wrap for long text.

## CSS custom properties
Colors/spacing defined once in :root and reused via var(--name).

## Vite gotcha
The default index.css centers the body with flex — replace it entirely.

## Testing
DevTools device toolbar at 320/375/768/1024/1440, check no horizontal scroll,
200% zoom, keyboard Tab navigation. Phones need the API URL reachable
(localhost means the phone itself).

## How it fits into Decision Journal
The app now has real styling that adapts from phone to desktop, with
accessible focus states and tap-friendly controls.

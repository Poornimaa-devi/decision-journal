# Day 66 — Decision Details

## Two approaches to "show one item in detail"
- URL-based routing (React Router) — proper approach, coming Day 79
- Local "selectedId" state — simpler, valid for now, used today

## Pattern
const [selectedId, setSelectedId] = useState(null);
const selected = items.find(i => i.id === selectedId);
if (selected) return <DetailView />; else return <ListView />;

## Where should state live? (important judgment call)
Not all state needs lifting up to the top. selectedId is a pure UI concern 
local to DecisionList — App.jsx doesn't need it. Rule of thumb: state 
should live in the LOWEST component that has access to everything it needs, 
lifted up only when multiple components genuinely need to share it.

## How it fits into Decision Journal
Decisions can now be viewed individually in full detail (reasoning, status), 
not just as compact list items — matching how a real journal entry should 
be readable in full when needed.

# Day 22 - Form Validation

## What is Validation?

Validation is the process of checking whether user input is correct before it is accepted by the application.

It helps ensure that only valid and meaningful data is stored.

---

## Why is Validation Important?

Validation prevents incorrect or incomplete information from entering the application. It improves data quality, reduces bugs, and provides a better user experience.

---

## Difference Between Valid and Invalid Input

### Valid Input

- Goal title contains at least 3 characters.
- Priority is High, Medium, or Low.
- Deadline is today or a future date.

### Invalid Input

- Empty goal title.
- Goal title with fewer than 3 characters.
- Invalid priority.
- Deadline earlier than today's date.

---

## What is Fail Fast?

Fail Fast is a programming principle where the application immediately stops processing when invalid input is detected.

Instead of continuing with bad data, the application shows an error message and waits for the user to correct the input.

---

## What Validations Does My Decision Journal Perform?

- Checks that the goal title is not empty.
- Ensures the goal title has at least 3 characters.
- Verifies that the selected priority is valid.
- Ensures the deadline is not in the past.

---

## Why Should Error Messages Be Meaningful?

Meaningful error messages clearly explain what is wrong and how the user can fix it.

Good error messages improve the user experience and help users correct mistakes quickly.

# Day 37 — MongoDB

## What is MongoDB?
A NoSQL database program that stores data as JSON-like documents, grouped into collections.

## Key Concepts
- **Document**: a single record, JSON-like, e.g. { title, priority, progress }
- **Collection**: a group of related documents (like goals, progress)
- **BSON**: the binary format MongoDB actually stores documents in (faster than plain JSON text, supports more data types)
- **_id**: an automatic unique ObjectId given to every document — replaces manual ID counters

## MongoDB Atlas vs Local MongoDB
- Atlas = cloud-hosted MongoDB, free tier available, closer to real production setup
- Local = MongoDB installed on your own machine

I chose Atlas because it avoids local installation issues and matches how the 
project will eventually be deployed.

## How it fits into Decision Journal
- `goals` array → `goals` collection
- `progressList` array → `progress` collection
- Manual `nextId` counter → replaced by MongoDB's automatic `_id`

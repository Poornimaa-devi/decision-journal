# Day 24 - UI Components

## What is a UI Component?

A UI component is a reusable part of the user interface that performs a specific task. Instead of building the entire webpage as one large section, we divide it into smaller, independent parts such as a header, dashboard, form, or goal card.

Examples:
- Header
- Dashboard Card
- Goal Card
- Search Bar
- Notification
- Footer

---

## Why are Components Reusable?

Reusable components save time and make the application easier to maintain.

For example, every goal in my project uses the same Goal Card design. Instead of creating different HTML for every goal, I use one template and display different data.

If I want to change the design later, I only need to update one template.

---

## Why Should UI Remain Consistent?

A consistent UI improves user experience because users always know where to find information.

Consistency includes:
- Same button styles
- Same card layout
- Same spacing
- Same fonts
- Same colors

A consistent interface looks professional and is easier to use.

---

## How Does Component Thinking Prepare Me for React?

React applications are built using reusable components.

Instead of creating one large HTML page, React divides the application into many small components.

Because my project is already organized into reusable sections like Goal Card, Dashboard, and Search Bar, it will be much easier to convert this project into React later.

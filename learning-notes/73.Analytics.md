# Day 73 — Analytics

## Aggregation pipeline
A series of stages that transform/compute data, different from find() 
(which only retrieves/filters raw documents). Used via Model.aggregate([...]).

## $group stage
Collapses documents into groups based on a field's value.
_id: "$fieldName" — the $ means "value of this field," not a literal string.
_id: null — one single group across everything (no splitting).

## Common accumulators
$sum: 1 — count documents in a group
$avg: "$field" — average of a field across the group
$cond: [condition, ifTrue, ifFalse] — conditional counting

## Aggregation always returns an array
Even grouping by null returns an array with one item — must handle the 
empty-array case (zero documents) with a fallback.

## How it fits into Decision Journal
Users can now see real computed insights (completion rate, stats by 
priority) instead of just raw lists — the beginning of the app's analytics 
features (Day 74 continues this).

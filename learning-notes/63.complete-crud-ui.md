# Day 63 — Complete CRUD UI (Phase 9 Review)

## The repeated pattern across all 4 operations
1. fetch() with appropriate method/headers/body
2. await response.json() if data expected
3. Update `goals` state correctly (set/append/map/filter depending on operation)
4. try/catch + error state for failures

## State update method per operation
- GET: setGoals(data) — replace entire array
- POST: setGoals([...goals, newItem]) — append
- PATCH: setGoals(goals.map(g => g._id === id ? updated : g)) — replace one
- DELETE: setGoals(goals.filter(g => g._id !== id)) — remove one

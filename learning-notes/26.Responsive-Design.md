# Day 26 – Responsive Design

## What is Responsive Design?

Responsive Design is a technique used to make a website automatically adjust its layout according to different screen sizes such as mobile phones, tablets, laptops, and desktops.

The content remains the same, but the layout changes to provide a better user experience.

---

## Why is Mobile-First Important?

Most users access websites using mobile devices.

Designing for mobile first helps developers create simple, clean, and user-friendly interfaces before expanding them for larger screens.

Benefits:
- Better user experience
- Faster loading
- Easier maintenance
- Works well on all devices

---

## Difference Between Flexbox and Grid

### Flexbox

- Used for one-dimensional layouts.
- Arranges items in rows or columns.
- Best for navigation bars, forms, buttons, and dashboard cards.

Example:

Dashboard Cards

Card Card Card Card

---

### Grid

- Used for two-dimensional layouts.
- Controls both rows and columns.
- Best for displaying multiple goal cards.

Goal3   Goal4

## What are Media Queries?

Media Queries allow different CSS styles to be applied based on the screen size.

Example:

If the screen width is small,
display elements vertically.

If the screen width is large,
display them horizontally.

This helps websites look good on every device.

---

## Why should websites use relative units?

Relative units automatically adjust according to the screen size.

Examples:
- %
- rem
- em
- vw
- vh

Unlike fixed pixels, they make layouts flexible and responsive.

---

## What I Learned

Responsive Design improves usability on different devices.

Flexbox is useful for arranging items in one direction.

Grid is useful for arranging items in rows and columns.

Media Queries change the layout based on screen size.

Relative units make websites flexible and user-friendly.

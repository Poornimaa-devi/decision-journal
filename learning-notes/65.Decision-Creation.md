# Day 65 — Decision Creation

## Decision vs Goal
- Decision: a CHOICE made, with reasoning (why)
- Goal: something being WORKED TOWARD
Related but distinct entities — a decision may lead to goals, but isn't one.

## Decision Schema
title (required), reasoning (required, longer text), status (enum: 
pending/decided/reviewing, default pending)

## Full CRUD built, following the EXACT same pattern as Goal
Model → Controller → Routes (protected from the start with authMiddleware) 
→ Frontend form. Proof that once a pattern (Day 40-41, 60-62) is learned 
deeply, applying it to a new resource is largely mechanical.

## New frontend element: <textarea>
Same controlled-component pattern as <input> — value + onChange — just 
suited for longer free text (reasoning).

## How it fits into Decision Journal
Decision is now the app's actual core entity, matching the project's real 
purpose — previously, Goals alone (while useful for learning) didn't 
represent the full product vision.

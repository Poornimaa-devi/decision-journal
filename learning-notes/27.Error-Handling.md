# Day 27 – Error Handling

## What is an Error?

An error is a situation where the application cannot perform an operation correctly. Errors may occur because of invalid user input, unexpected data, or programming mistakes.

Example:
- Empty goal title
- Invalid Local Storage data
- Editing a deleted goal

---

## What is an Edge Case?

An edge case is an uncommon situation that can cause unexpected behavior if not handled properly.

Examples in my project:
- No goals available.
- Searching for a goal that doesn't exist.
- Deleting every goal.
- Entering only spaces as a goal title.
- Refreshing the page multiple times.
- Cancelling an edit.
- Invalid data stored in Local Storage.

---

## What is Defensive Programming?

Defensive Programming means writing code that expects mistakes or unexpected situations and handles them safely instead of crashing.

Example:

- Check whether a goal exists before editing it.
- Validate user input before saving.
- Handle invalid Local Storage data.
- Show meaningful messages instead of errors.

---

## Difference Between Validation and Error Handling

### Validation

Validation checks whether user input is correct before processing it.

Example:
- Goal title must contain at least 3 characters.
- Deadline cannot be in the past.
- Progress must be between 0 and 100.

### Error Handling

Error handling deals with unexpected situations that occur while the application is running.

Example:
- Corrupted Local Storage.
- Editing a goal that no longer exists.
- Empty search results.

---

## Empty States in My Project

My application displays friendly messages when:

- No goals exist.
- No matching goals are found during search.
- No completed goals exist.
- Dashboard values are zero.

These messages improve the user experience by explaining what is happening.

---

## How My Application Recovers from Errors

- Invalid form input is rejected.
- Corrupted Local Storage loads an empty goals array.
- Users receive meaningful notifications.
- Invalid actions are prevented before they affect the application.
- The UI always reflects the current valid data.

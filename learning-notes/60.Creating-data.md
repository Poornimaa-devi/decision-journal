# Day 60 — Creating Data (Real POST Requests)

## fetch() for POST requires three things
1. method: "POST"
2. headers: { "Content-Type": "application/json" } — tells server how to 
   parse the body
3. body: JSON.stringify(data) — converts JS object to a JSON string 
   (HTTP bodies are text, not objects)

## Why Content-Type matters
Without it, Express's express.json() middleware can't parse req.body 
correctly — it would arrive as undefined even though data was sent.

## Using the REAL server response, not a local guess
After POST succeeds, use the actual returned document (with real _id, 
schema defaults applied) rather than manually constructing a fake version 
locally.

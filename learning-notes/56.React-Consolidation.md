# Day 56 — React Review (Phase 8 Wrap-up)

## Concepts consolidated (Days 50-55)
- Component: capitalized function returning JSX
- Props: read-only data passed from parent to child
- State: component-owned data, changeable via setter, triggers re-render
- Controlled forms: input value driven by state, updated via onChange

## Lifting state up
When multiple components need access to the same data, that data should 
live in their closest common parent, passed down via props. This is why 
App.jsx owns the `goals` array, not GoalForm or GoalCard individually.

## Pattern: passing functions as props
Children can trigger changes in a parent's state by calling a function 
the parent passed down (e.g. onAddGoal, and now onDeleteGoal) — without 
the child needing direct access to the parent's state itself.

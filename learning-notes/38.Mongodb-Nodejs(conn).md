# Day 38 — MongoDB + Node.js

## What is a database driver?
A library that lets Node.js communicate with MongoDB over the network. 
Mongoose serves as both the driver and (later) a schema/validation tool.

## Connection String
Format: mongodb+srv://<username>:<password>@cluster-address/databaseName
Contains login credentials — must NEVER be hardcoded, always stored in .env

## Why .env matters here
.env keeps MONGO_URI out of source code and out of GitHub (via .gitignore), 
protecting the database password from public exposure.

## Key Code
mongoose.connect(process.env.MONGO_URI)
  .then(() => console.log("Connected"))
  .catch((err) => console.error("Failed:", err.message));

- .then()/.catch() used because connecting to a remote server takes time 
  (asynchronous) — can't be handled with plain synchronous code.

## How it fits into Decision Journal
This is the literal bridge between my Express server and my MongoDB Atlas 
cluster. Without this, my goals/progress data has nowhere real to live.

# Day 88 — Deployment

## Architecture
Vercel (static React) → Render (Express API) → MongoDB Atlas.

## Environment variables
Backend variables are read at RUNTIME (NODE_ENV, MONGO_URI, JWT_SECRET,
CLIENT_ORIGIN, TRUST_PROXY). Frontend VITE_API_URL is baked in at BUILD time,
so changing it needs a redeploy. Secrets never go in Git.

## What breaks on first deploy
CORS (CLIENT_ORIGIN must match the frontend address exactly), https only,
SPA refresh 404 (vercel.json rewrite), missing env vars (server refuses to
start with a clear message), case-sensitive file names, TRUST_PROXY missing
(rate limiting sees only the proxy).

## Free tier
Render free web services spin down after 15 minutes idle (wake-up up to ~1
minute), have monthly hour limits, may restart any time, and have an
ephemeral filesystem. Open /health before a demo.

## Health check
GET /health returns {"status":"ok"} without auth or database.

# Day 28 – Week 4 Review

## What is Refactoring?

Refactoring is the process of improving the structure, readability, and maintainability of code without changing its functionality.

The goal of refactoring is to make the code easier to understand, modify, and debug.

---

## What are Code Smells?

Code smells are signs that the code can be improved. They are not necessarily bugs, but they indicate poor design or maintainability.

Common code smells include:

- Long functions
- Duplicate code
- Poor variable names
- Magic numbers
- Deep nesting
- Large files with mixed responsibilities

---

- Reviewed the HTML structure and removed unnecessary elements.
- Improved the organization of JavaScript functions.
- Ensured each function has a single responsibility.

- Checked for duplicate code and reused existing functions.

## What Would I Improve If I Rebuilt This Project?

If I rebuilt the project, I would:

- Use unique IDs everywhere instead of array indexes.
- Replace prompt() with modal dialogs.
- Split JavaScript into multiple files.
- Use reusable UI components.
- Add animations and better styling.
- Improve accessibility.
- Connect the project to a real database using MongoDB.
- Build the frontend using React instead of plain JavaScript.

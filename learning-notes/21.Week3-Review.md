# Day 21 - Week 3 Review

## 1. Explain the Complete Data Flow in My Project

The data flow in my Decision Journal project follows a structured process:

1. The user opens the application.
2. JavaScript loads the saved goals from Local Storage.
3. The goals array is restored.
4. The application calls renderGoals() to display all goals.
5. The application calls updateDashboard() to display goal statistics.
6. When the user creates a new goal, JavaScript reads the form data.
7. A new goal object is created.
8. The goal object is added to the goals array.
9. The updated array is saved to Local Storage.
10. renderGoals() updates the goal list.
11. updateDashboard() refreshes the dashboard statistics.

The same workflow is followed for updating and deleting goals.

---

## 2. What is the Source of Truth?

The source of truth is the **goals array**.

All features such as searching, filtering, sorting, rendering, and dashboard calculations use this array. The user interface never stores data by itself. Whenever the goals array changes, the UI is updated.

---

## 3. Why is renderGoals() Important?

The renderGoals() function converts the data stored in the goals array into visible HTML elements.

Instead of manually changing the webpage after every operation, I only update the data and call renderGoals(). This keeps the user interface synchronized with the latest data.

---

## 4. Why Should Every Function Have One Responsibility?

Each function should perform only one task.

For example:

- createGoal() creates a goal.
- editGoal() updates a goal.
- deleteGoal() removes a goal.
- renderGoals() displays goals.
- updateDashboard() updates dashboard statistics.
- saveGoals() stores data in Local Storage.

Keeping functions focused makes the code easier to read, debug, reuse, and maintain.

---

## 5. What is Separation of Concerns?

Separation of Concerns means dividing an application into different parts, where each part has a specific responsibility.

In my project:

- HTML handles the structure.
- CSS handles the design.
- JavaScript handles the application logic.
- Local Storage stores data.
- renderGoals() updates the user interface.
- updateDashboard() calculates statistics.

This organization makes the application cleaner and easier to extend.

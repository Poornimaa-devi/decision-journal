# Day 53 — Props

## What are props?
Data passed INTO a component from its parent, like function parameters. 
Allow one component definition to render differently based on what data 
it receives.

## Passing props
<ComponentName propName="value" numberProp={42} />
Attributes become keys in the props object automatically.

## Destructuring props (preferred style)
function GoalCard({ title, priority }) { ... }
Cleaner than writing props.title, props.priority repeatedly.

## Props are read-only
A component must never modify its own props. Data flows one direction: 
parent → child.

## Curly braces vs quotes
- Strings: propName="text"
- Numbers/booleans/expressions: propName={value}

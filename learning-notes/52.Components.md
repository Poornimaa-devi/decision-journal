# Day 52 — Components

## What makes a function a React component
1. Function name starts with a capital letter (distinguishes it from HTML tags)
2. Returns JSX (or null)

## JSX Rules
1. Must return exactly ONE root element (can wrap multiple elements in a parent div)
2. Use className, not class (class is a reserved JS keyword)
3. {curlyBraces} let you embed real JavaScript expressions inside JSX

## Using a component
Import it, then use it like a self-closing tag: <ComponentName />
Must be capitalized to be recognized as a component, not a literal HTML tag.

## export default
Required to make a component usable in other files via import.

## How it fits into Decision Journal
Built Header.jsx as the first real component, replacing Vite's default 
starter content in App.jsx. This establishes the pattern (small, focused, 
capitalized, exported) used for every future component: GoalCard, 
Dashboard, ProgressBar, etc.

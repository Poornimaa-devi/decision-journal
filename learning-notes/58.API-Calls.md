# Day 58 — API Calls

## fetch() basics
fetch(url) returns a Promise resolving to a Response object — NOT the data 
directly. Must call .json() (also async) to extract the actual JSON body.

## Async inside useEffect
useEffect's callback itself cannot be async directly. Correct pattern:
useEffect(() => {
  async function doFetch() { ... }
  doFetch();
}, []);

## Sending auth headers
fetch(url, { headers: { Authorization: `Bearer ${token}` } })
Required since goal/progress routes are protected (Day 49).

## response.ok
True for 200-299 status codes, false otherwise — used to catch errors 
(like 401) before trying to parse a response as valid data.

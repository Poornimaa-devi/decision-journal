# Day 71 — Search

## Query parameters
req.query reads values from the URL after ?, e.g. ?search=spanish
Different from req.params (:id, in the URL path) and req.body (request payload).

## MongoDB $regex search
Goal.find({ title: { $regex: searchTerm, $options: "i" } })
$options: "i" makes it case-insensitive.

## Making a filter optional
const filter = search ? { title: {...} } : {};
Empty object {} passed to find() means "no restrictions" — preserves 
original "get everything" behavior when no search term is given.

## useEffect with a real dependency
useEffect(() => {...}, [searchTerm]) — re-runs the fetch whenever searchTerm 
changes, the first genuine use of Day 57's "non-empty dependency array" pattern.

## encodeURIComponent
Safely encodes special characters in a value being placed into a URL — 
without it, spaces/symbols in search terms can break the request.

## How it fits into Decision Journal
Goals are now searchable by title, both in the database query and through 
a real frontend input — the dataset built up over Phase 10 is finally 
navigable at scale.

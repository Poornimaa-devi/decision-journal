# Day 20 - Dashboard

## What is a Dashboard?

A dashboard is a visual summary of important information in an application. It helps users quickly understand the current status without checking every individual record.

## What is Aggregation?

Aggregation means calculating summary values from a collection of data.

Examples:
- Total number of goals
- Completed goals
- Pending goals
- High priority goals

## Why Calculate Dashboard Values Instead of Storing Them?

Dashboard values should always be calculated from the original goals array. This keeps the information accurate and avoids inconsistencies if the data changes.

## What Information Does My Dashboard Display?

- Total Goals
- Completed Goals
- Pending Goals
- High Priority Goals

## Why Update the Dashboard After Every CRUD Operation?

Whenever a goal is created, updated, or deleted, the data changes. The dashboard must refresh to display the latest statistics.

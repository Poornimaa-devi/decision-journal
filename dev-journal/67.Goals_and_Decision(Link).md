# Day 67 — Goals (Linking Goals to Decisions)

## What I worked on
Added an optional decision reference to the Goal schema, used populate() in
the goal controller, and added a decision dropdown to GoalForm plus a
"From decision" line on GoalCard.

## What I learned
- Referencing vs embedding in MongoDB
- What ref and populate() do, and why every endpoint must return the same shape
- MongoDB doesn't enforce references the way SQL foreign keys do

## Key takeaway
The app's two main entities are finally connected, which is what turns
separate lists into a real journal.

# Day 27 – Development Journal

## Today's Goal

Improve the reliability of the Decision Journal by handling edge cases and unexpected situations.

---

## Edge Cases I Discovered

- Creating a goal with only spaces.
- Searching for unavailable goals.
- Deleting every goal.
- Cancelling goal editing.
- Refreshing after deleting all goals.
- Invalid data stored in Local Storage.

---

## Biggest Bug I Fixed

I improved the application so that invalid Local Storage data no longer crashes the application. Instead, it loads an empty goals list safely.

---

## What I Learned About Error Handling

I learned that applications should never assume everything will work correctly. They should validate user input, handle unexpected situations gracefully, and always provide meaningful feedback.

---

## One Improvement I'll Make Later

I want to replace browser prompts with modern popup dialogs and implement an Undo feature after deleting a goal.

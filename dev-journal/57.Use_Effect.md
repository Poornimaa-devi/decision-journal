# Day 57 — useEffect

## What I worked on
Added a useEffect with an empty dependency array to App.jsx, using 
console.log statements to observe exactly when it fires relative to 
component re-renders.

## What I learned
- Why side-effect code (like data fetching) can't live directly in a 
  component's render body
- The precise meaning of the dependency array: [], no array, and [value] 
  all behave very differently
- Confirmed experimentally that useEffect(() => {}, []) truly runs only once

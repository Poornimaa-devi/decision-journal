# Day 46 — JWT

## What I worked on
Installed jsonwebtoken, added JWT_SECRET to .env, and tested signing/verifying 
tokens with a standalone script.

## What I learned
- JWTs have three parts: header, payload, signature
- JWTs are readable by anyone (Base64, not encrypted) — only the signature 
  is protected, using the server's secret key
- Verifying with the wrong secret key correctly fails, proving the security 
  model works as expected

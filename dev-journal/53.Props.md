# Day 53 — Props

## What I worked on
Created GoalCard.jsx accepting title, priority, and progress as props, 
and used it three times in App.jsx with different data for each.

## What I learned
- Props work like function parameters for components
- Destructuring props directly in the function signature is the standard, 
  cleaner style
- Props are strictly read-only — data flows one direction, parent to child

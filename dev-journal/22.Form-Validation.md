# Day 22

## Today's Goal

Implement form validation to ensure only valid goals are added to the Decision Journal.

---

## What I Built

- Added validation for the goal title.
- Added validation for priority.
- Added validation for the deadline.
- Prevented invalid goals from being saved.
- Applied the Fail Fast approach in the application.

---

## Biggest Learning

I learned that validation should happen before any data is stored. This protects the application from invalid input and keeps the data reliable.

---

## Hardest Concept

Understanding how to stop the function immediately using `return` when validation fails.

---

## How Validation Improved My Project

Validation makes the application more reliable and user-friendly. It prevents incorrect data from being stored and ensures that only meaningful goals are saved.

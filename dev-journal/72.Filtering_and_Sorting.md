# Day 72 — Filtering & Sorting

## Building a multi-condition filter object
Start with filter = {}, conditionally add fields only if present in req.query.
Empty filter {} still means "no restrictions."

## Query parameters are ALWAYS strings
completed === "true" (string comparison) required — req.query.completed is 
never a real boolean, even if it looks like one in the URL.

## Sort shorthand
"-fieldName" = descending, "fieldName" = ascending (alternative to 
.sort({ field: -1 }) object syntax from Day 68).

## URLSearchParams
Browser built-in for safely building query strings with multiple parameters, 
handling encoding automatically — scales better than manual string building.

## How it fits into Decision Journal
Goals can now be searched, filtered by priority/status, and sorted — all 
combinable — making the dataset genuinely usable at real-world scale.

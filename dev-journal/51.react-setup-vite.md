# Day 51 — React Setup with Vite

## What I worked on
Created a new React project using Vite inside frontend/, installed 
dependencies, and ran the dev server for the first time.

## What I learned
- What Vite actually does (JSX conversion + fast dev server with HMR)
- The generated project structure — especially how main.jsx connects 
  React to the single <div id="root"> in index.html
- Frontend and backend are fully separate Node projects with independent 
  node_modules

## Key takeaway
I now have a real, running React development environment, separate from 
my Express backend, ready to build actual components starting tomorrow.

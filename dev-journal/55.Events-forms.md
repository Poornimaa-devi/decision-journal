## What I learned
- Controlled components: React state drives input values, not the DOM directly
- Why mutating state directly (push) is dangerous, and why spread operator 
  (...) creates the new array reference React needs
- How to pass a function as a prop, letting a child component trigger 
  behavior in its parent without knowing the implementation

## Key takeaway
Forms in React always follow the same shape: state for each field, 
value+onChange to control them, preventDefault on submit. This pattern 
will repeat for every form in this project (login, signup, reflections, etc).

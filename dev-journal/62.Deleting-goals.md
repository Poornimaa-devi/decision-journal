## What I worked on

API, removing goals from both the UI and MongoDB using filter() on array 
state.

## What I learned
- DELETE requests don't need Content-Type or a body — just the resource id
- filter() vs map(): removing an item vs replacing one within array state
- Why confirming server success before updating local UI state matters 
  for keeping frontend and backend truthfully in sync

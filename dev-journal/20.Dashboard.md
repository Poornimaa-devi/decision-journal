# Day 20

## Today's Goal

Learn how to create a dashboard that automatically displays statistics based on the goals array.

## What I Built

- Created a Dashboard section.
- Displayed total goals.
- Displayed completed goals.
- Displayed pending goals.
- Displayed high priority goals.
- Updated the dashboard automatically after every CRUD operation.

## Biggest Learning

I learned that dashboard values are derived from the goals array instead of being stored separately.

## Hardest Concept

Understanding that dashboard values should always be calculated from the latest data.

## How Dashboards Improve User Experience

Dashboards give users a quick overview of their progress without checking each goal individually. They make applications easier to use and understand.

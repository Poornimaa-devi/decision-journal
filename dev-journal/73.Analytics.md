# Day 73 — Analytics

## What I worked on
Built a /api/goals/analytics endpoint using MongoDB's aggregation pipeline 
($group, $sum, $avg, $cond), and a simple Analytics component to display 
the results.

## What I learned
- MongoDB's aggregation pipeline as a distinct tool from find()
- How $group, $sum, $avg, and $cond work together to compute statistics 
  at the database level
- Why computing stats in MongoDB scales better than fetching everything 
  and calculating in React

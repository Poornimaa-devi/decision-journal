# Day 83 — Responsive Design

## What I worked on
Replaced Vite's default index.css with a mobile-first stylesheet using CSS
variables, a flex navbar, grid card layout and styled forms; made small
markup changes (container/main layout, toolbar wrapper, aria-labels).

## What I learned
- Mobile-first with min-width media queries
- Flexbox for one-dimensional layout, Grid for two-dimensional
- auto-fill + minmax for responsive grids without breakpoints
- Touch target size, 16px inputs and visible focus for usability

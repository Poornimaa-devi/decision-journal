# Decision Journal

A personal productivity web application that helps users create goals, track their progress, and reflect on their journey. The project is being built step by step while learning modern web development concepts and will gradually evolve into a full-stack MERN application.

---

## Problem Statement

Many students, developers, and professionals create goals but struggle to organize them, monitor their progress, and stay consistent. Traditional note-taking applications store information but provide little support for tracking progress or making better decisions based on past experiences.

The Decision Journal solves this problem by offering a simple platform to create, manage, update, and monitor goals while laying the foundation for future decision tracking and personal analytics.

---

## Objectives

* Create and manage personal goals.
* Track goal progress using percentage completion.
* Monitor completed and pending goals.
* Search, filter, and sort goals efficiently.
* Store data locally using Local Storage.
* Learn software engineering principles while building a real project.
* Prepare the application for future migration to the MERN stack.

---

## Current Features

### Goal Management (CRUD)

* Create new goals
* View all goals
* Edit existing goals
* Delete goals

### Progress Tracking

* Progress percentage (0–100%)
* Automatic completion status
* Visual progress bar

### Dashboard

* Total Goals
* Completed Goals
* Pending Goals
* High Priority Goals

### Search, Filter & Sort

* Live search
* Filter by priority
* Sort by:

  * Title (A–Z)
  * Title (Z–A)
  * Deadline
  * Priority

### Data Persistence

* Local Storage integration
* Automatic loading after page refresh

### Form Validation

* Goal title validation
* Priority validation
* Deadline validation
* Progress validation

### User Experience

* Toast notifications
* Responsive design for mobile, tablet, and desktop
* Consistent UI components
* Progress badges and status indicators
